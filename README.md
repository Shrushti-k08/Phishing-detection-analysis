# Phishing-detection-analysis
This project focuses on the analysis of a potentially malicious website using url scanning tools to evaluate network behavior, external connections, and infrastructure patterns. It demonstrates practical skills in identifying suspicious activity, understanding web-based threats, and performing basic threat analysis in cybersecurity.
